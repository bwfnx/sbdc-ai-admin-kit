GPT to Skill

Sort all your custom GPTs at once, then turn the keepers into skills, one per chat, with a record of what changed.

Start here

What you get

Read this first if you just downloaded the kit: you may not need this skill at all. If your ChatGPT workspace has the one-click GPT migration, use it to convert. Then check each result with the kit's Skill Standard and testing method before advisors touch it. That's the whole job for most centers.

Use this skill when you have no migration button (Claude, or a workspace without it), or when you want help deciding what to migrate. It has two modes. Triage reads all your GPTs at once and says what each should become: a Skill, a Plugin, an Agent, merged into another, or retired. Convert turns one GPT into a skill, in its own chat, and hands you a ledger of what it kept, what it couldn't carry over, and which new guardrails it suggests.

It's for the person running AI at your center, not for advisors. Written for Maryland and points at Neoserra — check anything that touches your own CRM, programs, or reporting rules before you lean on it. MIT and unsupported — fork it, change it, don't wait on me.

Conversation skill. You start it by saying what you want; it asks for what it needs and hands back a deliverable in the same chat. Nothing to install beyond the plugin, nothing to configure.

What it never does

  • Never invents a trigger phrase. Derived triggers are marked "(inferred)".
  • Never adds a guardrail or restriction anywhere in the skill without your approval. Suggestions stay in the ledger.
  • Never drops an instruction silently. Every line of the GPT lands in the skill, a reference file, or the ledger.
  • Never paraphrases a list that has to match a system exactly, like CRM milestone names.
  • Never writes scripts. It flags where a calculation should become one.
  • Never converts more than one GPT per chat, and never opens Knowledge files during triage.
  • Never copies client data into a skill — real or sample, including examples inside a template.
  • Never says the converted skill works. Testing is your step, in a fresh chat.
  • Merge and Retire are recommendations, never decisions.

Step 1

What to have ready

  • For triage: one file, my-gpts.md, with every GPT in it: a ## GPT name heading, then its Description, Conversation starters, Knowledge file names, Capabilities, and the whole Instructions box, all copied from each GPT's Configure page.
  • Already saved each GPT as its own Word file? Don't re-paste. Put them in one folder, name each file after its GPT, and run py tools/gpts-to-md.py "C:\Users\you\Desktop\My GPTs" from the kit. It writes my-gpts.md for you, on your own computer.
  • For convert: the conversion card triage gave you (or that GPT's section of my-gpts.md), plus the GPT's actual Knowledge files — the originals you uploaded.

Step 2

Setting it up

Getting it on your side

The skill is plain instructions, so it runs wherever you already work. Pick your row:

  1. Get the files: everything is in the public GitHub repository. Click the green Code button, then Download ZIP. No GitHub account needed.
  2. ChatGPT: this skill is a plain Markdown file, not Claude-specific. Open skills/gpt-to-skill/SKILL.md, copy the whole file, and paste it into a ChatGPT Project’s instructions or a custom GPT. Same instructions, same outputs.
  3. Claude Code: /plugin marketplace add bwfnx/sbdc-ai-admin-kit then /plugin install sbdc-ai-admin-kit@sbdc-ai-admin
  4. ChatGPT Skills: on the repository page, click the green Code button, then Download ZIP. Unzip it and upload the skills/gpt-to-skill folder at chatgpt.com/skills.
  5. ChatGPT Work mode or Codex: switch the chat to Work mode (a regular chat can't install from GitHub) and say install https://github.com/bwfnx/sbdc-ai-admin-kit.

Your first conversation

Open a new chat and say:

Triage my GPTs

It will ask for:

  • your my-gpts.md file, if you didn't attach it
  • which of your GPTs people use every day, so those go first (skipped if you only gave it one)

Then open a new chat for each GPT you convert. That one habit matters more than anything else on this page: converting in a crowded chat is where quality drops.

Step 3

How to use it

Say

triage my GPTsconvert this GPT to a skillmigrate my GPTsturn these GPT instructions into a SKILL.md

What comes back

  • Triage: one table — each GPT's purpose, its verdict (Skill, Plugin, Agent, Merge, Retire), risk flags (knowledge, client-data, web/apps, no-refusals, math), and a suggested order. Then a conversion card for each Skill or Plugin, ready to paste into a new chat.
  • Convert: three summary lines (the skill's name; counts of confirmed guardrails, suggested guardrails, things lost, and script candidates; the one thing to look at first), then the skill folder to upload, a guardrail ledger, a guide spec for a staff page, and a test checklist.

Then

  • Answer yes or no on each Suggested guardrail in the ledger. Only the ones you approve go into the skill.
  • Install the new skill and run its test checklist in a fresh chat, the way a first-time user would. See TESTING.md.
  • Want a staff page like this one? Feed the guide spec to the kit's generator.

Tips from the field

  • Read the ledger's Lost in translation table before anything else. It lists what the GPT pointed to but the converter never saw, like a Knowledge file you didn't attach.
  • Results vary from run to run on the same GPT. Our worked example scored a narrow FAIL and lists what to check by hand on every conversion. Check those whichever way you converted.

Questions people ask

FAQ

I just downloaded the kit. What do I do first?
Three things, in order. 1) Convert your GPTs, with ChatGPT's one-click migration if you have it, or with this skill if you don't. 2) Before advisors touch any of them, score each against STANDARD.md and run it cold with TESTING.md. 3) Give staff a one-page guide for each skill. Everything else in the kit is optional.
OpenAI has a one-click migration. Why would I use this?
For the conversion itself, you probably won't. Use this skill if you have no button, if you're moving to Claude, or if you want triage first: which GPTs are duplicates, which should be agents, which to retire. Either way, the check in step 2 is the part that matters.
I have thirty GPTs saved as thirty Word files.
Put them in one folder, name each file after its GPT, and run py tools/gpts-to-md.py "<that folder>". No Python? In ChatGPT Work mode, Codex, or Claude, say "run tools/gpts-to-md.py from the sbdc-ai-admin-kit repo on my GPTs folder."
Does the converted skill just work?
Not until you've tested it. The skill won't tell you it works, on purpose. Run the test checklist it gives you in a fresh chat, and read the Lost in translation table.
Who do I ask when I'm stuck?
It's MIT and unsupported, so fork it and change it. Brandon Mason (Maryland SBDC) is happy to compare notes on the AI-Interest-Section thread.
